欢迎使用 · 配置向导

三步走完：Canvas → AI →（邮箱可选）。配置只写进你自己电脑的 .env，不会上传。

1. Canvas LMS 必填

从哪找 Token？
  1. 登录 Canvas，点左侧「账号」→「设置」
  2. 滑到页面底部「已批准的集成」，点「+ 新建访问令牌」
  3. 用途随便填（例如 ctm），有效期建议选到学期末，点「生成令牌」
  4. 复制那一串字符，粘贴到上面的输入框

令牌只保存在本机 .env 文件里。想撤销随时回 Canvas 删掉这个令牌即可。

2. AI 服务 必填

任何 OpenAI 兼容接口都能用（DeepSeek / OpenAI / 各家中转）。只用于把邮件和公告整理成任务清单。

3. 邮箱 可选

不配也能用：只监控 Canvas 的作业与课程公告。邮箱只用来额外捕捉「Canvas 之外的通知邮件」。

这里不做测试连接（IMAP 各家规则差异大，容易误报）。填错不影响 Canvas 部分，之后可以在 ⚙️ 设置里改。
